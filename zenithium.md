# Zenithium Solutions

Zenithium Solutions es una empresa de desarrollo de software ubicada en Mar del Plata, Buenos Aires, Argentina. Trabaja con empresas para diseñar, construir, integrar y mantener soluciones digitales.

## Servicios

- Desarrollo de software a medida.
- Desarrollo de sitios web, aplicaciones web y landing pages.
- Integraciones entre sistemas, APIs REST y desarrollo backend.
- Diseño, implementación y optimización de bases de datos con PostgreSQL y SQL Server.
- Automatización de procesos y soluciones de inteligencia artificial.
- Soluciones cloud con AWS y Azure, arquitecturas serverless, microservicios y DevOps.
- Ciberseguridad, protección de datos y buenas prácticas de seguridad.
- Diseño de interfaces y experiencia de usuario UI/UX.
- Consultoría tecnológica, arquitectura y soporte.

## Proyectos publicados

- [Fidebill](https://www.fidebill.com.ar/): Plataforma digital de fidelización con promociones, puntos, transacciones y ubicación de locales.
- [Saint Analytics](https://saintanalytics.com/): Aplicación web de análisis de datos con dashboards y reportes para instituciones.
- [El Molino](https://elmolinomdp.com.ar/): Tienda online de alimentos saludables y productos naturales con catálogo y búsqueda de productos.
- [Mia](https://soymia.com.ar/): Asistente con inteligencia artificial para automatizar consultas y turnos por WhatsApp, con agenda propia y reglas configurables.
